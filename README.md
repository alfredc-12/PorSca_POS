# PorSca POS

PorSca POS is a lightweight mobile point-of-sale system built with Expo and React Native for a semester Software Quality Assurance project.

Core scope:
- Mobile barcode scanning using the phone camera
- Cart and checkout flow
- Inventory management
- Cash payment recording and change calculation
- Dynamic QR Ph payment flow through PayMongo sandbox
- Transaction history
- Backend API for inventory, sales, and payment status

The app is designed for a single cashier operating from a phone. Inventory is deducted only when a sale is successfully paid.

See `docs/SETUP.md` for local setup and `docs/ARCHITECTURE.md` for the system structure.
